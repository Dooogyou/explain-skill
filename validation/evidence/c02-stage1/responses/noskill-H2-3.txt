C와 D의 차이는 다음과 같습니다.

| 항목 | 요금제 C | 요금제 D |
|---|---|---|
| 월 요금 | 3,000원 | 7,000원 |
| 동시 접속 | 1대 | 최대 4대 |
| 음악 스트리밍 | 가능 | 가능 |
| 음악 다운로드 | 불가 | 가능 |
| 결제 실패 시 | 새 곡 추가만 막힘 | 새 곡 추가만 막힘 |

**차이점**
- **가격**: D가 C보다 월 4,000원 비쌉니다. 약 2.3배입니다.
- **동시 접속**: C는 1대뿐이라 한 기기에서만 들을 수 있습니다. D는 최대 4대까지 동시에 쓸 수 있어 가족이나 여러 기기에서 함께 쓰기 좋습니다.
- **다운로드**: C는 스트리밍만 됩니다. D는 다운로드가 되므로 오프라인에서도 들을 수 있습니다.

**같은 점**
- 결제에 실패해도 두 요금제 모두 새 곡 추가만 막힙니다. 이 부분은 선택 기준이 되지 않습니다. 결제 실패 시 기존 곡 재생이 어떻게 되는지는 알려주신 내용에 없어서 말씀드릴 수 없습니다.

**선택 기준**
- 혼자 쓰고, 항상 인터넷이 연결된 환경에서 듣는다면 C가 저렴합니다.
- 여러 기기나 여러 사람이 함께 쓰거나, 오프라인 청취가 필요하다면 D가 맞습니다.
- 한 사람이 최대 4대를 쓰는 경우가 아니라면, 4,000원 차이는 사실상 다운로드 기능 값입니다.
