**요약:** B는 A보다 월 4,000원 더 비싸고, 사용 인원 상한(1명 → 최대 3명), 용량(10GB → 30GB), 오프라인(미지원 → 열람만 가능)이 더 넓습니다. 용량 초과 시 동작은 둘이 같습니다.

| 항목 | 가상 상품 A | 가상 상품 B |
|---|---|---|
| 월 요금 | 5,000원 | 9,000원 |
| 사용 인원 | 1명 | 최대 3명 |
| 용량 | 10GB | 30GB |
| 오프라인 | 미지원 | 열람만 가능 (열람 외 기능은 오프라인에서 허용되지 않음) |
| 용량 초과 시 | 새 업로드만 차단 (그 외 기능은 차단되지 않음) | 새 업로드만 차단 (그 외 기능은 차단되지 않음) |

**알아둘 점**
- **오프라인:** A는 오프라인 기능이 전혀 없습니다. B는 저장된 내용을 보는 것만 되고, 오프라인에서 열람 외의 작업은 할 수 없습니다.
- **용량 초과:** 둘 다 새 파일을 올리는 것만 막힙니다. 이미 올린 파일을 보는 것 등은 막히지 않습니다.
- **인원:** B의 "최대 3명"은 3명까지 쓸 수 있다는 상한입니다. 반드시 3명이 쓴다는 뜻은 아닙니다.

**원문에서 불분명한 부분**
- B의 30GB가 3명이 나눠 쓰는 전체 용량인지, 1인당 용량인지 적혀 있지 않습니다. 그래서 1인당 용량(10GB씩인지 등)은 계산하지 않았습니다.
- 1인당 요금도 실제 사용 인원에 따라 달라지므로 단정하지 않았습니다. 예를 들어 3명이 모두 쓴다고 가정하면 B는 1인당 3,000원이고, 1명만 쓰면 9,000원입니다. A는 1명 기준 5,000원입니다.
