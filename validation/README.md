## 후보 c02 — v1.1로 승격, 2026-10-14

c02는 c01을 바탕으로 했고, v1 대비 바뀐 부분은 [v1-to-v1.1.diff](v1-to-v1.1.diff)에 있다.

- “~일 때만”은 그 조건이 아니면 일어나지 않는다는 뜻이지, 조건을 만족하면 반드시 일어난다는 뜻이 아니라는 규칙을 넣었다. 핵심 문장·목록·표·비유 모두에 적용한다.
- “A만 된다/막힌다”는 그 밖의 것에 대한 정보도 담는다는 규칙을 넣었다.
- 조건을 표로 옮길 때 조건을 만족하는 칸에는 “할 수 있음(원문은 보장하지 않음)”을 쓰라는 규칙을 넣었다.
- 보내기 전 확인 항목을 하나 추가했다.
- c01의 계산 전 기준 확인 규칙은 그대로 두었다.

예시는 시험 문제와 다른 영역(회원 할인, 읽기 전용, 주말 운영)으로 썼다. name·description은 v1과 같다.

**시험 방법.** 결과를 보기 전에 계획과 통과 기준을 고정했다. 같은 CLI `2.1.292`, 요청 모델 `sonnet`(기록 `claude-sonnet-5-5`), `acceptEdits`로 실행했고, 각 실행은 새 세션이다.

- 1단계: c02로 T02-table, T02 원문, T03, 처음 보는 문제 H1(주차장 규칙), H2(음악 요금제)를 각 5회 실행했다. 비교를 위해 H1·H2를 v1과 스킬 미적용으로 각 3회 실행했다. 실행 순서는 무작위로 섞었다.
- 응답은 버전을 가린 무작위 ID로 판정했다. 판정을 저장한 뒤에 대응표를 열었다.
- 2단계: 1단계를 통과한 뒤 기존 사례 회귀를 14회 실행했다.

| 문제 | c02 | v1 | 스킬 미적용 |
| --- | --- | --- | --- |
| T02-table | **5/5** | (이전 기록 1/1 실패) | — |
| T02 원문 | **4/5** | (이전 기록 1/1 실패) | — |
| T03 | **4/5** | (이전 기록 3/3 실패) | (이전 기록 1/1 실패) |

- 1단계 기준(문제마다 5회 중 4회 이상, 합계 25회 중 21회 이상)을 22/25로 충족했다.
- **필요조건 → 충분조건 실패는 c02에서 한 번도 나오지 않았다.** 남은 c02 실패 3회는 T03의 “10분이 지난 뒤에는 켤 수 있습니다”라는 무조건 허용, T02 원문과 H2의 “그 밖은 알 수 없음”식 제한 약화 각 1회다.
- v1과 미적용은 H1에서 “등록 차량이면 열림”이라는 충분조건화나 “2시간 뒤 재입차 가능” 단정으로, H2에서 “기존 곡 재생은 알 수 없음”이라는 약화나 근거 없는 “오프라인 재생 가능”으로 실패했다.
- 2단계 회귀에서 T04·T05·T06·T08·T09-A·T10(4회)은 통과했고 T01 명시 호출도 통과했다. T01 자동 선택은 3/3이었으나 그중 1회는 표를 덧붙여 과잉 형식 실패였다. v1에서도 4회 중 1회 같은 실패가 있었다. T07은 통과했으나 가능한 설명 표의 가설 화살표 때문에 경계 사례로 표시했다.
- 2단계 중 6회는 사용량 한도로 거부돼 한도 해제 후 1회씩 다시 실행했다. 모두 정상 완료했다.

**한계.** c02 응답의 특유한 표현 때문에 판정자가 버전을 짐작할 수 있었다. 판정자는 시험을 설계한 같은 Claude다. 경계 사례는 다른 판정자의 교차 판정이 필요하다. 사례마다 3~5회라 통계적 유의성은 주장하지 않는다. 이전 기록과의 비교는 실행 시점과 환경이 다르다. Codex에서의 v1.1, 다른 모델·운영체제·UI는 시험하지 않았다.

1단계의 입력, 37개 응답 원문 전체, 응답별 판정과 근거 행은 [evidence/c02-stage1/](evidence/c02-stage1/judgments.json)에 있다. 2단계 응답 원문은 로컬에 보존했다.

## Codex의 별도 관찰과 보존된 실패

아래는 원본 v1에 대한 과거 저장 결과의 요약이다. Claude와 동일 조건 비교 또는 c01의 회귀 검증으로 합산하지 않는다.

- 2026-10-09 Codex CLI `0.162.0-alpha.2`, 요청 모델 `gpt-6.1-sol`에서 명시 호출 응답들을 확인했다. T02 원문 질문은 표 대신 목록을 선택했다. 표 지정 추가 시험과 T08의 추가 파일 읽기는 정책으로 차단된 이력이 있다.

- 위 네 시험에는 정상 실행과 별개로 초기화 실패 4회가 있다. T01·T02·T08의 본시험 전 환경 실패 각 1회와 T10-A의 사전 진단 환경 실패 1회다. 과거 정책 차단·elevated 초기화 오류·AGENTS.md 부재 오류·중간 도구 오류는 삭제하거나 해결됐다고 바꾸지 않았다.

## 미검증 범위와 근거 한계

v1.1과 원본 v1의 큰 표본 반복 안정성·완전 격리·내부 절대 비선택·사용자 이해도 향상은 미검증이다. v1.1은 Claude Code에서만 시험했다. Claude의 명령 허용 설정에서의 영상 생성·보이는 창의 HTML 애니메이션·실효 effort·데스크톱 UI/IDE·다른 OS도 미검증이다.
